# Kurt Magastino — Portfolio

Personal portfolio of **Kurt King D. Magastino**, BS Computer Science student at the University of the Cordilleras.

Plain HTML, CSS and JavaScript, with no framework and no build step. Light and dark themes, and a portrait that glides between Home and About.

## Pages

| Page | Status |
| --- | --- |
| **Home** | Name, role, tagline, CV download, social links |
| **About** | Short bio, facts, what I do |
| **Skills, Projects, Education, Family, Contact** | Coming soon |

## Run locally

Open the folder with any static server, for example:

```
python -m http.server 5500
```
